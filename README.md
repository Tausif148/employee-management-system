# Employee Management System

A modern and responsive employee management application built with React, TypeScript, Vite, and Supabase. The app enables user authentication, profile management, and employee data management through a clean and intuitive interface.

## Features

- User authentication and authorization
- Profile management
- Add and manage employees
- Employee data table with sorting
- Real-time data synchronization
- Protected routes
- Form validation
- Responsive design

## Tech Stack

- React 18
- TypeScript
- Vite
- Supabase
- React Query
- Formik
- React Router
- Tailwind CSS
